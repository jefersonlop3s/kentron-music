# Documentos legais do produto

Textos contratuais que acompanham o produto — **minutas**, não pareceres.

| Documento | O que é |
|---|---|
| [termo-de-uso](termo-de-uso.md) | Minuta do termo de aceite do usuário (e da instituição), com declarações, escopo, isenções e canal de notificação |

## Regras desta pasta

1. **Minuta, não decisão jurídica.** Nada aqui substitui a revisão do jurídico do dono. O texto se declara minuta em si mesmo, e é escrito para ser revisado — não para ser publicado sem revisão.
2. **Aprovação é do dono.** Publicar termo é ato do dono (é ele quem assume o risco), como o aceite de ADR.
3. **Fundamento rastreável.** Cláusula inspirada em prática de mercado aponta a fonte que a motivou, para que a revisão jurídica possa discordar com contexto.
4. **Nada de texto de terceiro.** A estrutura foi aprendida observando o mercado; o texto é nosso. Copiar minuta alheia seria trocar um problema por outro.
5. **Uma fonte por escopo:** o termo de uso vive aqui; o racional de licenciamento de letra vive na [ADR-0012](../adr/0012-letra-fonte-alinhamento-e-limites.md); o trabalho aberto vive no [PENDING](../PENDING.md).
